提示词工程师 · 让 AI 听懂需求

本任务不写代码，写提示词。把需求"翻译"给 AI，让它生成 new Swiper('#wySw4', {...}) 配置。
硬性要求：至少迭代 2 轮提示词，保留每轮提示词与 AI 回答；亲自粘进页面验证，截图 + 一句话结论。

📋 原始需求（必须全部满足）：
① 无缝循环　② 3.2 秒自动翻页且手动操作后不停止　③ 圆点分页器可点击　④ 初始效果为 cube
1

第 1 轮：模糊提示 → AI 大概率遗漏需求没有逐条明确，AI 自行发挥

👤 我的提示词（第 1 轮）
帮我写一个 Swiper 初始化配置，选择器是 #wySw4。要求：循环播放，每 3.2 秒自动切换，有圆点分页器，初始用 cube 效果。
🤖 AI 第 1 轮回答
new Swiper('#wySw4', { loop: true, autoplay: { delay: 3200 // 未显式写 disableOnInteraction: false → 若默认值为 true 手动后会停止 }, pagination: { el: '#wyPag4' // 缺 clickable: true → 圆点不能点击跳转 }, effect: 'cube' });

❌ 第 1 轮代码漏了什么？

  • autoplay 未显式写 disableOnInteraction: false —— 依赖 Swiper 默认值，若默认 true 则手动拖动后自动播放会停止，违反"手动操作后不停止"
  • pagination 缺 clickable: true —— 圆点不能点击跳转，违反"可点击"
2

第 2 轮：逐条拆解 → 精确命中把需求拆成编号清单，每条给出参数名+值

👤 我的提示词（第 2 轮）
帮我写 Swiper('#wySw4') 的完整配置对象，必须严格满足以下 4 条，缺一条都算错，只输出 JS 代码不要解释：
1. loop: true（无缝循环）
2. autoplay: { delay: 3200, disableOnInteraction: false }（每 3.2 秒自动翻页，且用户手动拖动后自动播放不停止）
3. pagination: { el: '#wyPag4', clickable: true }（圆点分页器可点击跳转）
4. effect: 'cube'（初始效果为 3D 立方体）
🤖 AI 第 2 轮回答
new Swiper('#wySw4', { loop: true, autoplay: { delay: 3200, disableOnInteraction: false }, pagination: { el: '#wyPag4', clickable: true }, effect: 'cube' });

✅ 第 2 轮代码：4 条需求全部命中

  • loop: true —— 无缝循环
  • delay: 3200 + disableOnInteraction: false —— 3.2 秒翻页且手动后不停
  • el: '#wyPag4' + clickable: true —— 圆点可点击
  • effect: 'cube' —— 初始 3D 立方体效果

答辩抽问准备点击展开参考答案

Q1：你的第一版提示词漏掉了哪个需求？

漏掉了两个细节：①"手动操作后不停止"——没有明确写出 disableOnInteraction: false；②"圆点可点击"——没有明确写出 clickable: true。第一版提示词用了"循环播放""自动切换""有圆点分页器"这种模糊描述，AI 只给了最基础的 delay 和 el，把这两个关键子参数省掉了。

Q2：你是怎么在第二轮里"说清楚"的？

把需求拆成 4 条编号清单，每一条都直接写出对应的 参数名和参数值，并且附上中文解释（如"用户手动拖动后自动播放不停止"）。同时加了约束语"缺一条都算错，只输出代码不要解释"，逼迫 AI 逐条对照，不让它自由发挥省略细节。

Q3：AI 第一次给的代码错在哪？

两处错误：① autoplay 只有 delay: 3200，没有 disableOnInteraction: false，导致用户手动滑动一次后自动播放就永久停止了；② pagination 只有 el: '#wyPag4'，没有 clickable: true，导致分页圆点只能看不能点，无法点击跳转。
