# 网页抓小球小游戏 — 完整规格说明 (spec.md)

## 1. 项目概述

一款基于浏览器的限时点击得分小游戏。玩家在 30 秒内尽可能多地点击屏幕上随机出现的蓝色小球获取分数，误点空白区域会扣分并刷新小球位置。

## 2. 技术栈

- HTML5（语义化结构）
- CSS3（Flexbox 布局、CSS keyframes 动画、伪元素）
- 原生 JavaScript（ES6+，无任何框架/库依赖）

## 3. 文件结构

```
wangyesheji123/
├── index.html       # 页面结构
├── style.css        # 所有样式和动画
└── script.js        # 游戏逻辑
```

## 4. 功能规格

### 4.1 游戏流程状态机

```
[初始状态] → 点击"开始游戏" → [游戏进行中] → 30秒倒计时归零 → [结束弹窗] → 点击"再来一局" → [游戏进行中]
     ↑                                                                              │
     └──────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 初始状态

- 页面顶部：信息栏（仅显示"分数：0"和"剩余：30秒"，或剩余时间显示为"—"）
- 页面中央：居中显示一个大号"🎮 开始游戏"按钮
- 页面上**无小球**
- 按钮为主要可交互元素

### 4.3 游戏进行中

#### 4.3.1 倒计时
- 点击开始按钮后，倒计时从 **30** 开始，每秒递减 1
- 倒计时在页面顶部右侧实时显示："剩余：X秒"
- 倒计时**到 0 即终止游戏**

#### 4.3.2 小球生成
- 游戏开始瞬间，立即在随机位置生成 **3 个小球**
- 小球为蓝色圆形（CSS `border-radius: 50%`），直径 **60px**
- 小球位置约束：
  - 在可视区域内（不超出视口）
  - 三个小球之间互不重叠（彼此圆心距离 > 60px）
  - 避开顶部信息栏区域（距顶部 > 80px）

#### 4.3.3 得分规则

| 行为 | 效果 | 视觉反馈 |
|---|---|---|
| 点中蓝色小球 | **+2 分** | 小球缩放至 0 消失 + 原地弹出绿色"+2"浮字向上飘动并淡出 |
| 点击空白区域 | **-1 分**（最低不低于 0） | 背景浅黄色短暂闪红 200ms + 三个小球**全部立即刷新**到新的随机位置 |

#### 4.3.4 刷新规则（双路径）

| 触发条件 | 刷新行为 |
|---|---|
| ✅ **点中命中**某个小球 | **仅**该小球在新随机位置重生，其余 2 个小球保持原位 |
| ❌ **点击空白**（扣分场景） | **全部 3 个小球**立即在新随机位置刷新 |

#### 4.3.5 事件冒泡处理
- 小球点击事件中必须调用 `event.stopPropagation()`，避免同时触发背景点击扣分
- 新小球淡入动画期间（300ms）设置 `pointer-events: none`，防止快速连点重复计分

> **修正**（回顾确认）：原需求第 4 条 "小球消失、随即刷新新随机位置小球" 实际含义：点中哪个，哪个就刷新。扣分时所有小球刷新。

### 4.4 页面顶部信息栏

```
┌─────────────────────────────────────────────────────┐
│  分数：14                              剩余：22秒    │
└─────────────────────────────────────────────────────┘
```

- 高度：60px，固定在页面顶部（`position: fixed`）
- 背景：白色半透明或浅黄色加深，保证与页面背景区分
- 左侧显示：`分数：<当前分数>`，字体加粗，字号 20px
- 右侧显示：`剩余：<秒数>秒`，倒计时 < 10 秒时文字变红色警示

### 4.5 游戏结束弹窗

倒计时归零后立即弹出：

```
┌──────────────────────┐
│      ⏱ 时间到！       │
│                      │
│    最终得分：16 分     │
│                      │
│   [ 🔄 再来一局 ]     │
└──────────────────────┘
```

- 居中模态弹窗（带半透明黑色遮罩）
- 显示游戏标题、最终分数
- 一个大号"再来一局"按钮，点击后：关闭弹窗 + 重置分数为 0 + 重置倒计时为 30 + 重新生成 3 个小球

### 4.6 结束弹窗状态

弹窗打开时：
- 背景页面上的小球**停止响应点击事件**（或直接从 DOM 移除）
- 倒计时停止
- 只能通过"再来一局"按钮重新开始

## 5. 视觉设计

### 5.1 色彩方案

| 元素 | 颜色 | 色值参考 |
|---|---|---|
| 页面背景 | 浅黄色 | `#FFF9C4` 或 `#FFFDE7` |
| 小球 | 蓝色（纯色实心） | `#2196F3` |
| 小球悬停 | 略加深 | `#1976D2` |
| +2 浮字 | 绿色 | `#4CAF50` |
| -1 闪红 | 红色叠层 | `rgba(244, 67, 54, 0.15)` |
| 信息栏 | 白底浅灰边 | `#FFFFFF` + `border-bottom: 2px solid #E0E0E0` |
| 倒计时警示 | 红色 | `#F44336` |
| 开始/重新开始按钮 | 主蓝色 | `#2196F3`，hover 变深 |

### 5.2 字体

- 整体：系统默认无衬线字体（`system-ui, -apple-system, sans-serif`）
- 信息栏：18–20px，加粗
- 弹窗标题：24px，加粗
- 弹窗分数：32px，加粗

### 5.3 动画规格

| 动画 | 时长 | 缓动 | 关键帧 |
|---|---|---|---|
| +2 浮字向上飘起并淡出 | 800ms | ease-out | 起点：原地 opacity 1 → 终点：上移 60px + opacity 0 |
| 小球缩放消失（点中时） | 300ms | ease-in | scale(1) → scale(0)，同时 opacity 1 → 0 |
| 新小球淡入出现 | 300ms | ease-out | scale(0) → scale(1)，opacity 0 → 1 |
| -1 背景闪红 | 200ms | linear | 背景色从正常 → 红色叠层 → 正常 |
| 弹窗淡入 | 300ms | ease-out | opacity 0 → 1，scale(0.9) → scale(1) |

## 7. 核心函数列表

| 函数 | 职责 |
|---|---|
| `startGame()` | 初始化游戏：重置分数、重置倒计时、生成 3 个小球、启动计时器 |
| `endGame()` | 结束游戏：清除计时器、移除小球 DOM、弹出结束弹窗 |
| `spawnBalls(count)` | 生成指定数量的小球，随机定位，加入 DOM |
| `spawnSingleBall(excludeIds)` | 在不与现有小球重叠的前提下，生成 1 个小球并返回其数据 |
| `getRandomPosition()` | 返回 { x, y }，保证在有效区域内且不重叠 |
| `handleBallClick(ballElement, scoreDelta)` | 小球被点中：加/扣分、触发动画、移除旧球、生成新球 |
| `handleBackgroundClick()` | 点击空白区域：扣 1 分（不低于 0）、背景闪红、所有小球刷新位置 |
| `updateScoreDisplay()` | 更新顶部分数显示 |
| `updateTimeDisplay()` | 更新顶部倒计时显示，< 10 秒时变红 |
| `showEndModal()` | 显示结束弹窗 |
| `hideEndModal()` | 隐藏结束弹窗 |

## 8. 边界条件处理

| 场景 | 处理方式 |
|---|---|
| 扣 1 分后分数变成负数 | 分数下限为 0，不允许负数 |
| 点击到小球的同时也触发了背景点击 | 小球点击事件中调用 `event.stopPropagation()`，阻止冒泡到背景 |
| 倒计时最后 1 秒内点击 | 正常处理点击，但倒计时到 0 时仍立即结束游戏 |
| 小球随机位置超出可视区域 | `getRandomPosition()` 内做边界检查，小球中心距边缘 ≥ 40px |
| 三个小球生成时彼此太近 | 生成时做距离检查，若 < 60px 则重新生成位置 |
| 快速连续点击同一小球（动画未结束） | 使用 `pointer-events: none` 在动画期间禁用点击，避免重复计分 |
| 游戏进行中用户按 F5 刷新 | 无持久化存储，刷新后回到初始状态 |

## 9. 浏览器兼容性

- 目标浏览器：Chrome / Edge / Firefox 最新版
- 不使用任何需要 polyfill 的 API
- `requestAnimationFrame` 可选用于更平滑的动画，但非必需
- 纯 CSS keyframes 动画，无需 JS 动画库
